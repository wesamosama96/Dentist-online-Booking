<h1 style="font-size: 3rem; color: white;">INTRODUCTION</h1>

<h1 style="font-size: 2rem; color: white;">Purpose</h1>
The purpose of this project is to develop a web-based Dentist Clinic Management System that helps organize clinic operations digitally.

The system aims to improve appointment scheduling, patient organization, and clinic workflow efficiency.

<h1 style="font-size: 2rem; color: white;">Scope</h1>
This system will provide a platform for:

- patient registration and login
- appointment booking and cancellation
- dentist schedule management
- administrative control over users and appointments

This project focuses on core clinic management features and does not currently include payment processing or advanced analytics.

## Definitions
- **Patient**: A user who books appointments
- **Dentist**: A medical professional managing treatments
- **Admin**: A system manager responsible for user and appointment administration.
- **Appointment**: A scheduled meeting between patient and dentist
