<h1 style="font-size: 3rem; color: white;">INTRODUCTION</h1>

<h1 style="font-size: 2rem; color: white;">Purpose</h1>
The system will allow patients to book appointments, dentists to manage schedules, and administrators to control system data.


<h1 style="font-size: 2rem; color: white;">Scope</h1>
The system will allow patients to book, re-schedule, or cancel appointments, dentists to manage schedules as well, and administrators to control system data.

## Definitions
- **Patient**: A user who books appointments
- **Dentist**: A medical professional managing treatments
- **Appointment**: A scheduled meeting between patient and dentist
