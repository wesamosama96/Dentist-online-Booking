## System Description
This project is a Full-stack <strong style="color: teal">Dentist Appointments booking </strong> system that facilitates the process of booking and reduces the jam at the clinic reciptions by making the booking process smart and easy-to-access.

## Goals
- Simplify appointment booking
- Reduce manual scheduling errors
- Provide organized access to patient and appointment information
- Improve clinic workflow efficiency

## Target Users

- Patients
- Dentists
- Administrators

## Tech Stack (Tentative)
- Frontend: React, TailwindCSS
- Backend: Node.js / Express
- Database: MongoDB
