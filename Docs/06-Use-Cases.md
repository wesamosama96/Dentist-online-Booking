<h1 style="font-size: 3rem; color: white; text; text-transform: uppercase">Use Cases</h1>

## Use Case: Book Appointment

Actor: Patient

Steps:
1. User logs in
2. Selects available date
3. Chooses dentist
4. Confirms booking


## Use Case: Cancel Appointment

Actor: Patient

Steps:
1. User logs in
2. Selects the target appointment
4. State the reason for cancellation
5. Request Cancellation


## Use Case: Re-Schedule Appointment

Actor: Patient

Steps:
1. User logs in
2. Selects the target appointment
3. Choose the new appointment date and time
5. Request re-schedule


## Use Case: re-schedule Appointment

Actor: Dentist

Steps:
1. User logs in
2. Selects the target appointment
3. State the reason for re-scheduling
4. Choose the new date and time for the appointment
5. Request re-schedule


## Use Case: Approve re-schedules

Actor: Dentist

Steps:
1. User logs in
2. Selects the target appointment
3. Approve or reject the re-schedule
5. Confirm re-scheduling


## Use Case: Manage Appointments

Actor: Admin

Steps:
1. Admin logs in
2. Views all appointments
3. Updates or deletes records

## Use Case: Manage Users

Actor: Admin

Steps:
1. Admin logs in
2. Views all users
3. Adds or deletes users
