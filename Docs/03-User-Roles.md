<h1 style="font-size: 3rem; color: white; text; text-transform: uppercase">User Roles</h1>

## Patient
- Register/Login
- Book appointments 
- Requst appointment rescheduling or Cancelling
- View appointment history

## Dentist
- Login
- View daily schedule
- Update appointment status
- Add treatment notes (Future Phase)

## Admin
- Manage users
- Manage appointments
- View overall clinic activity
- Update or remove records when needed
