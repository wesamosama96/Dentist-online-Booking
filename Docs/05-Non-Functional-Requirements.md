<h1 style="font-size: 3rem; color: white; text; text-transform: uppercase">Non-functional Requirements</h1>


## Performance

- The system should respond to user actions within 2 seconds under normal conditions.

---

## Security

- User authentication is required.
- Access should depend on user role.
- Sensitive data should not be publicly accessible.

---

## Usability

- The user interface should be simple and easy to understand.
- Main actions should be accessible with minimal navigation.

---

## Reliability

- The system should store and retrieve appointment data consistently.

---

## Maintainability

- The codebase should follow a clear structure to support teamwork and future updates.
