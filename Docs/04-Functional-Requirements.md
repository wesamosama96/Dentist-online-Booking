<h1 style="font-size: 3rem; color: white; text; text-transform: uppercase">Functional Requirements</h1>

## Authentication

### FR1 
The system shall allow users to register an account.

### FR2
The system shall allow users to log in using email and password.

---

## Patient Features

### FR3
The system shall allow patients to book appointments.

### FR4
The system shall allow patients to Request appointments Cancellation.

### FR5
The system shall allow patients to Request appointments re-scheduling.

### FR6
The system shall allow patients to view their booked appointments.

---

## Dentist Features

### FR7
The system shall allow dentists to view their schedules.

### FR8
The system shall allow dentists to update appointment status.

### FR9
The system shall allow dentists to approve appointment re-scheduling.

### FR10
The system shall allow dentists to request appointment cancellation.

---

## Admin Features

### FR11
The system shall allow admins to manage users.

### FR12
The system shall allow admins to manage appointments.
