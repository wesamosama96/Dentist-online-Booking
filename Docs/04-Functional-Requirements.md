<h1 style="font-size: 3rem; color: white; text; text-transform: uppercase">Functional Requirements</h1>

## Authentication
FR1: The system shall allow users to register with proper validation
FR2: The system shall allow users to log in with proper authentication check

## Appointments
FR3: The system shall allow patients to book appointments  
FR4: The system shall allow patients to requrest appointment rescheduling and canceling   
FR5: The system shall allow dentists to view schedules and approve the patients requests  

## Management
FR6: The system shall allow admins to manage users
