# Dentist Clinic Management System

A full-stack web application developed as part of a diploma project.

The system is designed to help manage dentist clinic operations such as patient registration, appointment booking, schedule management, and administrative control.

---

## Project Status

Current phase: **Phase 1 – Planning and Requirements Analysis**

Phase 1 focuses on defining the project foundation, including:

- project overview
- user roles
- functional requirements
- non-functional requirements
- use cases
- initial system design
- UI/UX planning
